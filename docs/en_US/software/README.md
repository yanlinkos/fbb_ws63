# Documentation Introduction

## 1. How to Obtain the WS63 Series User Guide

[WS63 Series User Guide](https://hispark-obs.obs.cn-east-3.myhuaweicloud.com/WS63%E7%B3%BB%E5%88%97%E7%94%A8%E6%88%B7%E6%8C%87%E5%8D%97.pdf) mainly introduces the basic functions of the WS63 series and provides users with the function descriptions, application scenarios, and application configuration methods of the WS63 series.

## 2. How to Obtain the WS63 Series Hardware User Guide_04.pdf

[WS63 Series Hardware User Guide_04](https://hispark-obs.obs.cn-east-3.myhuaweicloud.com/WS63%E7%B3%BB%E5%88%97%E7%A1%AC%E4%BB%B6%E7%94%A8%E6%88%B7%E6%8C%87%E5%8D%97_04.pdf) mainly introduces the package and pin information, electrical characteristic parameters, schematic design suggestions, PCB design suggestions, thermal design suggestions, soldering process, moisture sensitivity parameters, interface timing, and precautions of the WS63 series.

## 3. Materials Introduction

| Name                    | Description                                                  |
| ----------------------- | ------------------------------------------------------------ |
| IO Multiplexing.md      | There are 19 IO ports in total, with a diagram of the functions supported by each pin |

| HTTP Development Guide  | This document mainly introduces the development and implementation examples of the HTTP Client function |
| lwIP Development Guide  | This document introduces the relevant content of lwIP (A Lightweight TCP/IP stack), including the lwIP introduction, application development, network security, and common issues |
| MQTT Development Guide  | This document mainly introduces the development and implementation examples based on the MQTT function |
| release-notes           | This document mainly introduces the version description file |
| NV Storage User Guide   | This document mainly introduces the use of the NV storage module in WS63V100, to guide engineers to quickly use the NV module for secondary development |
| SDK Development Environment Setup User Guide | This document introduces the WS63 chip SDK development environment (including SDK compilation and application development), to help users quickly understand the development environment and compile executable files for secondary development |
| TLS-DTLS Development Guide | This document mainly introduces the development and implementation examples of the TLS/DTLS component |
| Security Software Development Guide | This document mainly describes the structure of the CIPHER DRIVER and the usage of its software interfaces |
| Third-Party Software Porting Guide | This document describes in detail the build operation guidance for porting third-party software to the SDK on WS63V100, and also provides common questions and answers and troubleshooting methods |
| Quick Start Guide       | This document is written for developers who use the version for the first time, to help them quickly grasp the overall architecture of the document and guide developers to develop step by step |
| Software Development Guide | This document describes in detail the Wi-Fi, BLE&SLE interface functions and development process of WS63V100 |
| Device Driver Development Guide | This document mainly introduces the WS63 device driver development, mainly including working principles, interface usage methods described by scenario, and precautions |
| Feature Development Guide | This document describes in detail the application scenarios, implementation principles, and interface descriptions of WS63V100-related features, so that readers can understand and use the related features conveniently |
| File System User Guide  | This document mainly introduces the use of the LITTLE FILE SYSTEM (hereinafter referred to as LFS) file system module in WS63V100 |
| ws63-Document-Cn.chm    | This document describes in detail all driver APIs of the SDK |
