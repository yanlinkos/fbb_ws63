# WS63 1.10.103 Release Notes

## 1. Improvements over the Previous Base Version

| Serial No. | Category | Change Description | Remarks |
| --- | --- | ------- | --- |
| 01  | WiFi Module Optimization   | 1. Adjusted channel scanning parameters to improve the scan success rate.<br>2. The driver supports transmission of fragmented pbufs of the LWIP protocol stack.<br>3. Optimized the packet transmission success rate of SoftAP in interference environments, improving performance in interference scenarios.<br>4. Resolved the issue where a small number of received packets were probabilistically lost right after association in repeated disconnection and re-association scenarios, and added application-layer packet loss or retransmission handling.<br>5. Optimized the scanning process so that, in the unassociated scenario, the device returns to the previously configured working channel after scanning.<br>6. Fixed the compilation error when enabling the SNTP function in LWIP.<br>7. The MQTT component is provided in the form of a patch.|     |
| 02  | BLE/SLE Module Optimization | 1. Committed the SLE interconnect interoperability changes to the repository to meet the consistency requirements of the SLE certification protocol.<br>2. Optimized SLE connection stability. Resolved the probabilistic link-drop issue in scenarios involving SLE connection parameters and repeated disconnection.<br>3. Optimized scheduling in BLE/SLE + Wi-Fi coexistence scenarios, resolving the probabilistic SLE link-drop issue and the high-probability Wi-Fi disconnection caused by repeated BLE scanning.<br>4. The BLE Sample supports the write property of characteristic values.<br>5. Adjusted the rate configuration of the BLE Sample; the speed test supports the PHY 2M rate.<br>6. Optimized SLE flow control to improve throughput-test stability. |     |
| 03  | System and Peripheral Optimization    | 1. Simplified the SSB/Flashboot startup prints during the boot phase to reduce serial port information output, making it easier for customers to share the serial port.<br>2. Optimized the parameters of the AT+CUSTOMEFUSE command to support multiple writes.<br>3. Enhanced the printing of task test information in AT+SYSINFO.<br>4. Resolved the issue where, in UART interrupt mode, receiving fewer than 16 bytes of data did not report the interrupt in time, causing serial port reception delays.<br>5. Resolved the issue where the clock signal was not output in SPI Master mode when data was read without writing.<br>6. OTA upgrade scenarios now support sector-by-sector flash erase, reducing the time occupied by a single flash erase operation and minimizing the impact on data transmission services.<br>7. PWM channel parameters support configuration of 8 channels and support low-frequency (below 1 kHz) PWM output. |     |
| 04  | Sensing Module Optimization     | 1. Optimized the detection trigger latency in interference scenarios.<br>2. Added an isolation range statistics function to the parameter calibration tool.<br>3. Optimized the algorithm to improve detection distance and reduce false alarms in different scenarios. |     |
